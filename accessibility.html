Website support

Accessibility

PCS Truck Sales aims to provide a website that works with keyboards, screen readers, browser zoom, reduced-motion preferences, and mobile devices.

Current support

The site uses semantic headings, visible keyboard focus, skip links, descriptive image alternatives, large touch targets, responsive layouts, readable contrast, and phone and email links written in plain text.
