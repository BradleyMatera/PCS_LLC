# PCS LLC Website Concepts

Five complete static website directions for PCS LLC, a Rockford-area business associated with bucket trucks and specialized work-truck equipment.

- Version 4, Heavy Metal: `https://bradleymatera.github.io/PCS_LLC/v4/`
- Version 5, Truck Board: `https://bradleymatera.github.io/PCS_LLC/v5/`

## Verified scope used in the demos

- PCS LLC is the business name supplied by Tyler.
- Tyler publicly posts bucket trucks and specialized work trucks for sale.
- The business is described only as operating in the Rockford, Illinois area.
- Facebook is the only published contact method in this review build.

The demos intentionally do not publish a home address or invent a phone number, dealership status, certifications, financing, delivery, warranties, or a confirmed public repair-service menu.

## Technical foundation

- Static HTML, CSS, and minimal JavaScript
- Mobile-first responsive layouts
- Semantic HTML and keyboard-visible focus
- Canonical URLs and social metadata
- Organization and FAQ structured data
- `robots.txt`, `sitemap.xml`, and `llms.txt`
- Privacy and accessibility pages
- GitHub Pages deployment workflow
